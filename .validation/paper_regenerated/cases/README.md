# Recorded provenance cases

Three separate Qwen3-14B qualitative requests, drawn from the archived
semantic cases. Three separately displayed requests, with no aggregation.
Native width: 3.50 inches, for a single-column appendix figure.
Layout: three parallel requests across four boxed evidence layers.
Responses and token tables have small insets; signed evidence uses
aligned labels/digests. Settlement values are retained with concise
bill-consistency and protocol-audit labels on single lines.
PNG: 1200 dpi. PDF and SVG are vector graphics. Latin text uses Times
New Roman; the Chinese response/token glyph uses Microsoft YaHei.
The translation source sentence is original Chinese; other prompt
excerpts are English translations. Response strings and token IDs
are copied from the original records. Stored audit results are reported.
The generator checks bundled token counts, selected token positions, receipt
usage, charge arithmetic, settlement sums, and text containment.
No inference, TEE, or proof generation is executed by this script.
