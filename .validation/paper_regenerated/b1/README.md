# B1 request traces and throughput preview

Five columns are the five evaluated models. Top panels contain all four schemes, three rounds of 128 measured requests each; lines break at round boundaries. Request indices are submission indices, not completion order or elapsed time. Latency is request_pipeline_ns / 1e9, including the measured request processing path but not time waiting in the evaluation executor before execute() starts. Each request includes eight sequential model calls.

Bottom panels show per-scheme arithmetic means and sample standard deviations of three batch throughput observations; each batch uses 128 / batch_wall_seconds. Individual round observations are preserved. No per-request throughput is inferred from reciprocal latency or reconstructed from missing completion timestamps.

All plot text uses Times New Roman. Legends are inside subplots. Dark colors and four distinct line styles identify schemes. Four white hatch patterns on dark bars, black outlines, and black-bordered round markers support grayscale reproduction. A separate grayscale PNG/PDF is exported for print review. The wider, shorter layout uses end-aligned request ticks and padded exports to avoid clipping 384. The Phi latency axis spans 60--190 s and retains every measured value; all throughput axes retain a zero baseline. No caption is added to the image. Callouts deliberately emphasize favorable observed differences only; all unfavorable observations remain visible in the full curves, bars, round points and error bars and are retained in annotation_values.json. Top dashed boxes enclose all TP/Vanilla data in round 3 where its mean latency is lower; arrows point from boxes to explanatory labels. Bottom callouts show the percentage difference of three-round mean throughput relative to Vanilla where positive. The same round/comparison is used for every model, without searching other rounds for a favorable result. These callouts are selected highlights and do not summarize all model results. Exact annotation values are exported to annotation_values.json. These ratios and differences do not establish causal acceleration.

Y-axis ranges differ by model. Shared GPU load, placement, and actual output lengths vary. All observations are retained. No model inference or rerun is performed. The two CSV files contain all plotted numeric data.
